The application rejects paid dispatch while retaining public originals, manual/local controls and already recognized browser data; configured fake development remains explicitly labelled. A restart invalidates prior-epoch grants and loses process counters, so do not treat it as a global allowance reset mechanism. Confirm unavailable capability responses and zero unexpected provider starts before reopening. Record real usage/balance and rollback revision without copying content or secrets into the report.
